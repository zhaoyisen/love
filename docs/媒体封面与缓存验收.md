# 媒体封面与缓存验收

本次修复：视频审核通过后生成 480 像素宽、自动纠正旋转方向的 JPG 封面；图片详情优先读取压缩展示图。已有 READY 媒体缺少缩略图时，后端每轮最多补齐 5 个；失败至少间隔 60 秒重试，补图不会重新发布记录或重复通知。

前端将实际显示过的图片和视频封面保存到账号隔离的本地文件，按资产 ID 和对象路径复用，签名变化不再导致重下封面。上限 100 个文件、总计 32 MB、单张 2 MB，7 天未使用会过期。首次打开尚未缓存的封面仍需要网络；再次打开先显示已有记录和本地封面，再同步最新记录。视频内容按需播放，不预下载完整视频。

会话失效、账号切换、解绑及重置会清理缓存；服务端返回的最新列表会移除不再授权的封面。对方封面的本地复用受 COS 签名有效期限制，过期后等待接口重新授权，避免缓存延长权限窗口。缓存不替代服务端权限判断。

## 发布

1. 将修复提交到 develop 并合并 main，通过现有 Jenkins 部署后端。启动时 Flyway 自动执行 V20 补图查询索引。
2. 确认生产 COS 桶已开通数据万象视频截帧/媒体处理，后端凭据拥有相应处理和输出对象权限。API 和 COS 域名继续使用当前合法域名配置。
3. 部署后无需重新上传已有视频，后台会自动补图。持续失败时查看 `Media thumbnail will retry`、`COS video thumbnail failed` 日志，并在 COS 控制台检查处理权限及源视频格式。
4. 重新上传小程序体验版（客户端版本 `1.0.8`）；缓存和首屏优化需要更新前端包才能生效。完成以下验收后再提审发布。

## 真机验收

- [ ] 旧视频与新上传的视频都出现实际画面封面；详情页先显示封面，点击后播放。
- [ ] 首次浏览等待封面显示，然后退出小程序并重新打开：首屏先显示最近记录和封面，再后台同步；接口刷新签名时封面不闪回空白。
- [ ] 下拉刷新和切换日期仍返回最新内容；加载中的媒体处理完成后，首页会轻量轮询更新封面（最多 12 次，离开页面停止）。
- [ ] 两个账号切换、解绑后重新邀请、删除/改为私密后刷新，对方不再看到已撤销权限的封面。
- [ ] 微信清理本地文件或弱网时，封面回退到远端请求，页面可重试；大批浏览后缓存仍有容量上限。

本地自动验证：`node --test scripts/test-media-covers.js scripts/test-couple-reinvite.js`、`npm run typecheck`、`npm run validate`，以及 Maven 后端测试。真机耗时、实际 COS 权限和已有生产数据的补图结果需在部署后的体验版验证。
