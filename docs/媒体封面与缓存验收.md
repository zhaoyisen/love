# 媒体封面与缓存验收

本次修复：视频审核通过后生成 480 像素宽、自动纠正旋转方向的 JPG 封面；图片详情优先读取压缩展示图。已有 READY 媒体缺少缩略图时，后端每轮最多补齐 5 个；失败至少间隔 60 秒重试，补图不会重新发布记录或重复通知。

前端将实际显示过的图片和视频封面保存到账号隔离的本地文件，按资产 ID 和对象路径复用，签名变化不再导致重下封面。上限 100 个文件、总计 32 MB、单张 2 MB，7 天未使用会过期。首次打开尚未缓存的封面仍需要网络；再次打开先显示已有记录和本地封面，再同步最新记录。视频内容按需播放，不预下载完整视频。

会话失效、账号切换、解绑及重置会清理缓存；服务端返回完整列表时移除不再授权的封面，最新 50 条这样的分页结果不会误删历史封面。对方封面的本地复用受 COS 签名有效期限制，过期后等待接口重新授权，避免缓存延长权限窗口。缓存不替代服务端权限判断。

2026-10-15 补充修复：列表封面加载后立即采用持久文件路径，刷新不再取消仍被允许的缓存写入；详情页也缓存图片展示图，先显示已保存内容再同步。封面比例采用现有页面使用的占位写法，修复兼容性风险，仍需真机检查。

“我们”新增上传照片入口，每次 1～9 张 JPG、PNG、WEBP，单张不超过 20 MB。照片仅加入当前共同相册，不自动创建记录。页面展示最近 6 张，查看相册可预览接口返回的最近 100 张独立照片；更大相册的分页浏览尚未实现。处理中的照片仅上传者可见，审核通过后双方可见；解绑后对方失去接口访问权限。成功照片不再被当成 24 小时未发布的孤立文件清理，失败或被拦截的相册上传仍按孤立文件保留期清理。部分批次失败不影响已加入的照片继续处理和刷新。

头像保存会等待媒体处理成功，使用服务端图片地址；失败时保留原头像并显示错误，不再误报成功。超过等待时间可再次保存，待处理资产 ID 会随账号状态保存，退出编辑页后可恢复；重新选图、保存成功或切换账号时清除。未关联到个人资料的待处理上传仍受服务端孤立文件保留期限制，超期后需重新选择。时间线、我们、我的、详情、短评及回应头像展示统一使用已保存资料，图片错误时回退首字。

2. 确认生产 COS 桶已开通数据万象视频截帧/媒体处理，后端凭据拥有相应处理和输出对象权限。API 和 COS 域名继续使用当前合法域名配置。
3. 部署后无需重新上传已有视频，后台会自动补图。持续失败时查看 `Media thumbnail will retry`、`COS video thumbnail failed` 日志，并在 COS 控制台检查处理权限及源视频格式。
4. 重新上传小程序体验版（客户端版本 `1.0.9`）；缓存、相册和头像优化需要更新前端包才能生效。完成以下验收后再提审发布。

## 真机验收

- [ ] 旧视频与新上传的视频都出现实际画面封面；详情页先显示封面，点击后播放。
- [ ] 首次浏览等待封面显示，然后退出小程序并重新打开：首屏先显示最近记录和封面，再后台同步；接口刷新签名时封面不闪回空白。
- [ ] 下拉刷新和切换日期仍返回最新内容；加载中的媒体处理完成后，首页会轻量轮询更新封面（最多 12 次，离开页面停止）。
- [ ] 两个账号切换、解绑后重新邀请、删除/改为私密后刷新，对方不再看到已撤销权限的封面。
- [ ] 微信清理本地文件或弱网时，封面回退到远端请求，页面可重试；大批浏览后缓存仍有容量上限。
- [ ] 浏览封面后，在“甜蜜”与其他页之间切换、进入详情后返回：已有封面保持显示。超过 50 条记录时，历史封面也不应被普通刷新清理；详情展示图尚未缓存时仍需下载。
- [ ] “我们”直接上传多张照片：共同相册出现照片，“甜蜜”记录数量不增加；另一账号处理前不可见、成功后可见，解绑后访问被拒绝。
- [ ] 批次中途失败时，成功上传的照片仍继续刷新；后台处理期间关闭页面再打开也可继续刷新。
- [ ] 上传头像后保存，检查我的、我们、甜蜜顶部、详情作者、回应和短评。处理失败无成功提示，处理超时退出再打开可恢复待保存头像。

本地自动验证（2026-10-15）：前端全量 65/65、后端 50/50、`npm run typecheck`、`npm run validate` 均通过。后端包含相册访问权限、解绑撤权、独立照片不发布记录、成功照片清理保护、失败照片清理，以及两个独立事务交错提交时相册归属和处理状态不丢失的回归测试。迁移在 H2 MySQL 兼容测试库执行通过，未执行生产迁移。真机耗时、实际 COS 权限和已有生产数据的补图结果需在部署后的体验版验证；本次未推送或部署。
