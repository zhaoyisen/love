# 恋爱笔记低保真交互原型

这是根据《恋爱笔记微信小程序产品需求文档 PRD v1.0》制作的可点击低保真原型，用于验证交互路径与信息架构，不代表最终视觉稿。

## 打开方式

直接打开 `index.html` 即可。建议使用本地静态服务器，以获得更稳定的浏览器行为：

```powershell
python -m http.server 4173 --directory outputs/love-notes-lowfi
```

然后访问 `http://127.0.0.1:4173/`。

## 覆盖流程

1. 首次使用与首条记录
2. 图片、视频、纯文字记录
3. 图片模板美化
4. 邀请另一半与模拟接受
5. 天、周、月、年、自定义时间视图
6. 表情回应与短评
7. 双人云宠物
8. 年度回顾编辑、敏感内容排除与预览
9. 单方解绑及内容隔离说明

桌面端左侧提供五条评审任务的快捷入口。原型状态保存在当前浏览器的 `localStorage` 中，可随时重置。

## 本轮不验证

- 真实微信登录、授权、订阅消息和分享
- 真实图片上传、Canvas 合成和相册保存
- 后端接口、对象存储和内容安全检测
- 拖拽排序、视频播放和服务端生成进度
- 最终品牌视觉、宠物美术和动效
