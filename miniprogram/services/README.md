# 小程序远端联调层

当前页面仍默认使用 `core/mock-api.ts`，保证没有云资源时可以完整演示。

本目录已经提供真实后端请求、token 刷新、登录、情侣、时刻和媒体上传会话客户端。下一步完成 COS 小程序直传与媒体 Worker 后，再把页面数据源整体切换，避免出现一半本地、一半远端的数据分叉。

联调模拟器前：

1. 启动 `server`；
2. 保持 `core/api-config.ts` 为 `http://127.0.0.1:8080/api/v1`；
3. 开发者工具本地设置中临时勾选“不校验合法域名”；
4. 真机时必须改为手机可访问的 HTTPS 域名，不能使用 `127.0.0.1`。

永久密钥不得进入本目录或任何小程序代码。
