# 恋爱笔记微信小程序

基于《恋爱笔记微信小程序产品需求文档 PRD v1.0》《技术详细设计说明书 v1.0/v1.1》和低保真交互原型 v0.1 实现的原生微信小程序客户端 MVP。

如果你的目标是从当前代码直接走到正式发布，请只按[《生产上线唯一操作手册》](docs/生产上线唯一操作手册.md)从第 1 步执行。

## 运行

1. 安装依赖：`npm install`
2. 执行检查：`npm run validate && npm run typecheck`
3. 使用微信开发者工具导入本目录。当前 `appid` 为 `touristappid`，可直接体验本地 mock 流程；真实联调时替换为正式 AppID，并在 `miniprogram/core/api-config.ts` 设置 HTTPS API 地址和 `useRemoteApi: true`。

第一次开发微信小程序，请按[零基础运行、测试、部署与上线指南](docs/零基础运行部署上线指南.md)逐项操作。导入开发者工具时必须选择包含 `project.config.json` 的项目根目录，不能选择 `miniprogram` 子目录。

准备上传照片和视频时，请先阅读[腾讯云 COS 私有对象存储接入指南](docs/腾讯云COS私有对象存储接入指南.md)。COS 必须使用私有桶、服务端临时凭证和短期下载地址，永久密钥不能进入小程序。

后续功能迭代请参考[功能缺口与开发优先级清单](docs/功能缺口与开发优先级清单.md)。该文档按 PRD v1.0、详细设计 v1.1 和当前代码状态整理未完成任务、优先级与验收口径。

## 已实现

- 首次登录、隐私承诺和未配对独立使用
- 天/周/月/年/自定义五种时间视图及心情筛选
- 图片、视频、纯文字三类记录，3 秒草稿保存、属性与可见范围约束
- 6 套图片模板、发布前预览和本地发布闭环
- 一次性邀请、共享规则确认、情侣空间与应用内信笺
- 时刻详情、6 种回应、单层短评、删除与 30 天回收站
- 云宠物、每日幂等互动和共同日志
- 年度回顾候选、敏感内容默认排除、编辑、披露检查、生成状态和相册长图保存
- 默认可见范围、提醒设置、单方解绑和数据隔离说明

## 真实联调状态

登录、昵称、邀请、配对、记录、时间线、删除恢复、回应、短评、应用内信笺、云宠物和腾讯云 COS 媒体已经接入统一 `/api/v1`。生产媒体会经过文字/图片/视频审核；图片生成去 EXIF 的展示图和缩略图，回收站与孤儿上传有自动清理任务。客户端状态不作为权限安全边界。

年度回顾的候选、选择、草稿和生成状态已经接入真实服务端；预览页会在小程序端用 Canvas 生成长图并保存到手机相册，长图文件不上传 COS、不作为服务端资产保存。后端说明见 [server/README.md](server/README.md)。

服务端生产发布采用 Jenkins + Docker Compose，配置和首次部署步骤见 [Jenkins + Docker Compose 服务端部署指南](docs/Jenkins-Docker-Compose服务端部署指南.md)。`develop` 分支只执行构建与测试，`main` 分支通过后自动发布生产容器。
