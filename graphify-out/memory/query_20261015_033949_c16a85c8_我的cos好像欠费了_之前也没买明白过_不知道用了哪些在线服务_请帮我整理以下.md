## 6. 建议处理顺序

1. **先由账户持有人清偿欠费并留出正余额**，暂不因为报错盲目新购 COS/CDN 大套餐。已买资源包并不保证账户可以长期零余额使用。
2. 等待控制台停服提示解除。控制台提示充值后可能延迟几分钟恢复；恢复后重试一张旧照片、一张新头像、一次视频封面生成。
3. COS/CI 恢复后核对现有资源包的实际剩余量、抵扣明细和全部桶资源用量。CI 图片处理包虽然按订单仍在期限内，不能据此断言其剩余量充足。
4. 按 7～30 天实际用量决定是否续容量包、买 COS 外网流量包或继续按量计费。当前账单样本存储量远小于 50GB，没有证据支持直接扩大容量套餐。
5. CDN 先不再购买。已有 100GB 完整未消耗；后续确需接入时，应单独设计私有源站鉴权、客户端访问鉴权和费用限制，不能将情侣私密照片直接改为公开读。
6. 余额预警值得设置，但本次未替用户修改通知、自动充值或续费设置。

**需要及时处理的风险：** 官方欠费规则说明停服后数据只保留有限时间，持续欠费可能导致数据销毁；停服期间保留数据仍可能产生容量费用，失败请求也可能计费。本次没有核对欠费起始时间，因此不推算本账户确切销毁日期。不要点击控制台的“删除所有数据”来处理这次欠费。
